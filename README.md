
このプロジェクトは、**[函館大会](https://sites.google.com/view/u16procon-hakodate/)向けに開発された[CHaserWebシステム](https://github.com/shin3391/CHaserWeb)をベースに、[舞鶴大会](https://www.u15-maizuru.org/)向けにカスタマイズしたWebアプリケーション**です。

- [舞鶴大会推奨ライブラリ](https://github.com/U15-maizuru/pyCHaser) 

注意：公式のサーバーと同一の動作を保証するものではありません。

## 機能

- Pythonコードをブラウザ上で編集・実行
- ゲームの進行状況をリアルタイムで表示
- プレイヤー・対戦AI双方のプログラムのアップロード、ダウンロード（対戦AI側も自由に差し替え可能）
- 「CHaser」向けのプログラムの開発・デバッグが容易に行えます

## セキュリティ上の注意

アップロードされたファイルはサーバに保存・送信されず、ブラウザ内でのみ扱われます。ただし、**アップロードしたプログラムはあなたのブラウザ上でそのまま実行されます**（Pyodide上で動作しますが、ページと同じ権限を持ちます）。

- **配布元が確認できないファイルはアップロードしないでください。** 自分で書いたプログラム、または信頼できる相手から受け取ったファイルだけを使用してください。
- 公開時は `render.yaml` の `Content-Security-Policy` により、ページから到達できる読み込み元・通信先を必要最小限に限定しています。Render以外の環境で公開する場合は、同等のヘッダを設定してください。
- アップロードできるファイルサイズは1MBまでです。マップのサイズは5〜40、ターン数は1〜999の範囲に制限されます。
