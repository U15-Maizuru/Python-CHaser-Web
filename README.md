
このプロジェクトは、**[函館大会](https://sites.google.com/view/u16procon-hakodate/)向けに開発された[CHaserWebシステム](https://github.com/shin3391/CHaserWeb)をベースに、[舞鶴大会](https://www.u15-maizuru.org/)向けにカスタマイズしたWebアプリケーション**です。

- [舞鶴大会推奨ライブラリ](https://github.com/U15-maizuru/pyCHaser) 

注意：公式のサーバーと同一の動作を保証するものではありません。

## 機能

- Pythonコードをブラウザ上で編集・実行
- ゲームの進行状況をリアルタイムで表示
- プレイヤー・対戦AI双方のプログラムのアップロード、ダウンロード（対戦AI側も自由に差し替え可能）
- 「CHaser」向けのプログラムの開発・デバッグが容易に行えます
